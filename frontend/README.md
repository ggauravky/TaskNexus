# TaskNexus frontend

React 18 and Vite single-page application styled with Tailwind CSS. See the repository [README](../README.md) for setup, environment variables, deployment, and verification instructions.

Useful commands:

```bash
npm run dev
npm run lint
npm run build
npm run preview
```

Access tokens are held in memory. Session restoration is reconciled with the API through the protected refresh cookie and `/api/auth/me`.
